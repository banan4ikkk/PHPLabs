### Задание 2. Цикл `for`
Сначала был использован цикл `for`, в котором переменные `$a` и `$b` изменялись на каждом шаге. Также был добавлен вывод промежуточных значений.

```php
<?php
$a = 0;
$b = 0;

for ($i = 0; $i <= 5; $i++) {
    $a += 10;
    $b += 5;
    echo "Шаг $i: a = $a, b = $b<br>";
}

echo "End of the loop: a = $a, b = $b";
```

После завершения цикла получаем:
- `a = 60`
- `b = 30`

### Задание 3. Цикл `while`
Далее тот же самый цикл был переписан с использованием оператора `while`.

```php

while ($i <= 5) {
    $a += 10;
    $b += 5;
    echo "Шаг $i: a = $a, b = $b<br>";

}

echo "End of the loop: a = $a, b = $b";
```

### Задание 4. Цикл `do-while`
После этого цикл был переписан с использованием `do-while`.


## Контрольные вопросы

### 1. В чем разница между циклами `for`, `while` и `do-while`? В каких случаях лучше использовать каждый из них?
Цикл `for` обычно применяется тогда, когда заранее известно количество повторений.  
Цикл `while` используется в тех случаях, когда количество повторений заранее неизвестно, и выполнение должно продолжаться, пока условие остаётся истинным.  
Цикл `do-while` отличается тем, что его тело выполняется как минимум один раз, потому что условие проверяется после выполнения кода внутри цикла.

### 2. Как работает тернарный оператор `? :` в PHP?
Тернарный оператор — это сокращённая форма записи условного оператора `if...else`.

Общий вид:
```php
условие ? значение_если_истина : значение_если_ложь;
```

Пример:
```php
$age = 20;
echo ($age >= 18) ? 'Совершеннолетний' : 'Несовершеннолетний';
```

Если условие истинно, возвращается первое значение, иначе — второе.

### 3. Что произойдет, если в `do-while` поставить условие, которое изначально ложно?
Даже если условие изначально ложно, тело цикла `do-while` всё равно выполнится один раз, так как проверка условия происходит только после первого выполнения.
