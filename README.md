# BookHub

## Индивидуальная работа по PHP

**Тема проекта:** разработка традиционного веб-приложения средней сложности с функционалом на стороне сервера.

**Название проекта:** `BookHub`

**Описание проекта:**  
`BookHub` — это веб-приложение для просмотра и управления каталогом книг. В проекте реализованы регистрация пользователей, вход в систему, роли пользователей, публичный каталог книг, поиск, добавление книг и административная панель.

## Инструкции по запуску проекта

### 1. Установка локального сервера

Для запуска проекта используется локальный сервер `XAMPP`.

Необходимо запустить следующие модули:

- `Apache`
- `MySQL`

---

### 2. Размещение проекта

Папку проекта необходимо скопировать в директорию:

```text
C:\xampp\htdocs
```

Итоговый путь к проекту должен быть таким:

```text
C:\xampp\htdocs\bookhub
```

---

### 3. Импорт базы данных

Для работы проекта нужно импортировать базу данных.

Порядок действий:

1. Открыть браузер.
2. Перейти по адресу:

```text
http://localhost/phpmyadmin
```

3. Создать базу данных с названием:

```text
bookhub
```

4. Открыть вкладку `Import`.
5. Выбрать файл:

```text
database.sql
```

6. Нажать кнопку `Go`.

После этого будут созданы таблицы `users`, `genres` и `books`.

---

### 4. Настройка подключения к базе данных

Файл подключения к базе данных находится по пути:

```text
config/database.php
```

Пример настроек подключения:

```php
$host = 'localhost';
$databaseName = 'bookhub';
$username = 'root';
$password = '';
```

Для стандартного XAMPP пользователь базы данных — `root`, а пароль обычно пустой.

---

### 5. Запуск проекта

После запуска `Apache` и `MySQL` нужно открыть сайт в браузере:

```text
http://localhost/bookhub/public/index.php
```

---

### 6. Данные администратора

Для входа в административную панель используется аккаунт администратора:

```text
Email: admin@example.com
Password: admin123
```

`BookHub` — это веб-приложение, которое позволяет пользователям просматривать каталог книг, искать книги, добавлять новые записи и управлять данными через административную панель.

Проект состоит из нескольких основных частей:

- публичная часть сайта;
- система регистрации;
- система входа в аккаунт;
- защищённая часть для авторизованных пользователей;
- административная панель;
- база данных MySQL;
- клиентская и серверная валидация форм.

## Функциональные возможности

### 1. Регистрация пользователей

Пользователь может создать новый аккаунт.

Форма регистрации содержит:

- имя пользователя;
- email;
- пароль;
- повтор пароля.

Пароль не сохраняется в базе данных в открытом виде. Для его защиты используется функция:

```php
password_hash($password, PASSWORD_DEFAULT);
```

---

### 2. Вход в систему

Пользователь может войти в систему по email и паролю.

Проверка пароля выполняется с помощью функции:

```php
password_verify($password, $user['password']);
```

После успешного входа данные пользователя сохраняются в сессии:

```php
$_SESSION['user_id'] = $user['id'];
$_SESSION['username'] = $user['username'];
$_SESSION['role'] = $user['role'];
```

---

### 3. Выход из системы

Пользователь может выйти из аккаунта.

При выходе данные сессии очищаются:

```php
$_SESSION = [];
session_destroy();
```

---

### 4. Публичная главная страница

Главная страница доступна всем пользователям без авторизации.

На ней отображаются последние добавленные книги из базы данных.

Пример SQL-запроса:

```php
$stmt = $pdo->query(
    "SELECT books.*, genres.name AS genre_name
     FROM books
     JOIN genres ON books.genre_id = genres.id
     ORDER BY books.created_at DESC"
);
```

---

### 5. Каталог книг

На странице каталога отображаются все книги, которые находятся в базе данных.

Для каждой книги выводится:

- название;
- автор;
- жанр;
- год издания;
- статус;
- кнопка для просмотра подробной информации.

---

### 6. Просмотр подробной информации о книге

Пользователь может открыть отдельную страницу книги.

На странице отображаются:

- название книги;
- автор;
- жанр;
- год издания;
- статус;
- пользователь, который добавил книгу;
- полное описание книги.

---

### 7. Добавление книги

Авторизованный пользователь может добавить новую книгу.

Форма добавления книги содержит следующие поля:

- название книги;
- автор;
- жанр;
- год издания;
- описание;
- статус.

Форма содержит больше 5 полей разных типов:

- текстовые поля;
- числовое поле;
- выпадающий список;
- поле `textarea`;
- кнопка отправки формы.

---

### 8. Поиск книг

В проекте реализована форма поиска.

Пользователь может искать книги:

- по названию;
- по автору;
- по жанру.

Пример фрагмента SQL-запроса для поиска:

```php
$sql = "SELECT books.*, genres.name AS genre_name
        FROM books
        JOIN genres ON books.genre_id = genres.id
        WHERE 1=1";

if ($query !== '') {
    $sql .= " AND (books.title LIKE :query OR books.author LIKE :query)";
    $params[':query'] = '%' . $query . '%';
}

if ($genreId !== '') {
    $sql .= " AND books.genre_id = :genre_id";
    $params[':genre_id'] = (int)$genreId;
}
```

---

### 9. Защищённые страницы

Некоторые страницы доступны только после входа в систему.

Например:

- добавление книги;
- редактирование книги;
- удаление книги;
- административная панель.

Проверка авторизации выполняется через функцию `requireAuth()`.

```php
function requireAuth(): void
{
    if (!isLoggedIn()) {
        redirect('/bookhub/public/login.php');
    }
}
```

---

### 10. Роль администратора

В проекте есть две роли пользователей:

- `user` — обычный пользователь;
- `admin` — администратор.

Роль хранится в таблице `users` в поле `role`.

Администратор имеет дополнительные возможности:

- просмотр всех пользователей;
- создание новых администраторов;
- просмотр всех книг;
- добавление книг;
- редактирование любых книг;
- удаление любых книг;
- доступ к административной панели.

Проверка администратора выполняется через функцию `requireAdmin()`.

```php
function requireAdmin(): void
{
    requireAuth();

    if (!isAdmin()) {
        redirect('/bookhub/public/index.php');
    }
}
```

## Структура базы данных

В проекте используется база данных MySQL с названием:

```text
bookhub
```

База данных состоит из трёх основных таблиц:

- `users`
- `genres`
- `books`

---

### Таблица `users`

Таблица `users` хранит данные пользователей.

```sql
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    role ENUM('user', 'admin') NOT NULL DEFAULT 'user',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### Поля таблицы `users`

| Поле | Тип | Описание |
|---|---|---|
| `id` | `INT` | Уникальный идентификатор пользователя |
| `username` | `VARCHAR(50)` | Имя пользователя |
| `email` | `VARCHAR(100)` | Email пользователя |
| `password` | `VARCHAR(255)` | Хешированный пароль |
| `role` | `ENUM('user', 'admin')` | Роль пользователя |
| `created_at` | `TIMESTAMP` | Дата создания аккаунта |

---

### Таблица `genres`

Таблица `genres` хранит жанры книг.

```sql
CREATE TABLE genres (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE
);
```

#### Поля таблицы `genres`

| Поле | Тип | Описание |
|---|---|---|
| `id` | `INT` | Уникальный идентификатор жанра |
| `name` | `VARCHAR(100)` | Название жанра |

---

### Таблица `books`

Таблица `books` хранит информацию о книгах.

```sql
CREATE TABLE books (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(150) NOT NULL,
    author VARCHAR(100) NOT NULL,
    genre_id INT NOT NULL,
    year INT NOT NULL,
    description TEXT NOT NULL,
    status ENUM('available', 'unavailable') NOT NULL DEFAULT 'available',
    user_id INT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (genre_id) REFERENCES genres(id) ON DELETE RESTRICT,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE SET NULL
);
```

#### Поля таблицы `books`

| Поле | Тип | Описание |
|---|---|---|
| `id` | `INT` | Уникальный идентификатор книги |
| `title` | `VARCHAR(150)` | Название книги |
| `author` | `VARCHAR(100)` | Автор книги |
| `genre_id` | `INT` | Внешний ключ на таблицу жанров |
| `year` | `INT` | Год издания |
| `description` | `TEXT` | Описание книги |
| `status` | `ENUM('available', 'unavailable')` | Статус книги |
| `user_id` | `INT` | Пользователь, который добавил книгу |
| `created_at` | `TIMESTAMP` | Дата добавления книги |

---

### Связи между таблицами

#### Связь `genres` → `books`

Один жанр может относиться ко многим книгам.

Тип связи:

```text
1 ко многим
```

Пример:

```text
Один жанр "Фантастика" может быть у многих книг.
```

---

#### Связь `users` → `books`

Один пользователь может добавить много книг.

Тип связи:

```text
1 ко многим
```

Пример:

```text
Один пользователь может добавить несколько книг в каталог.
```

## Безопасность проекта

В проекте реализованы основные требования безопасности.

---

### 1. Хеширование паролей

Пароли не хранятся в базе данных в открытом виде.

Для создания хеша используется:

```php
password_hash($password, PASSWORD_DEFAULT);
```

Для проверки пароля используется:

```php
password_verify($password, $user['password']);
```

---

### 2. Защита от SQL-инъекций

Для работы с базой данных используется PDO и подготовленные запросы.

Пример:

```php
$stmt = $pdo->prepare("SELECT * FROM users WHERE email = :email LIMIT 1");
$stmt->execute([':email' => $email]);
```

Такой способ защищает приложение от SQL-инъекций.

### 3. Защита от XSS

Для безопасного вывода данных используется функция `htmlspecialchars()`.

В проекте создана вспомогательная функция:

```php
function e(?string $value): string
{
    return htmlspecialchars($value ?? '', ENT_QUOTES, 'UTF-8');
}
```

Она используется при выводе данных на страницу:

```php
<?= e($book['title']) ?>
```

### 4. Защита закрытых страниц

Для защиты закрытых страниц используется сессия.

Если пользователь не вошёл в систему, он перенаправляется на страницу входа.

```php
function requireAuth(): void
{
    if (!isLoggedIn()) {
        redirect('/bookhub/public/login.php');
    }
}
```

### 5. Проверка роли администратора

Для доступа к админ-панели проверяется роль пользователя.

```php
function requireAdmin(): void
{
    requireAuth();

    if (!isAdmin()) {
        redirect('/bookhub/public/index.php');
    }
}
```

### 6. Валидация данных

В проекте используется два типа проверки:

- клиентская проверка;
- серверная проверка.

Клиентская проверка выполняется с помощью HTML и JavaScript.

Пример HTML-проверки:

```html
<input type="text" name="title" required minlength="2" maxlength="150">
```

Серверная проверка выполняется в PHP.

Пример:

```php
if (strlen($title) < 2 || strlen($title) > 150) {
    $errors[] = 'Название книги должно содержать от 2 до 150 символов.';
}
```
