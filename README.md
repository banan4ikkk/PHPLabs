## Контрольные вопросы
### 1. Какие способы установки PHP существуют?
Существует как минимум 2 способа установки PHP:
- установка вручную с официального сайта
- установка XAMPP для быстрой настройки среды

### 2. Как проверить, что PHP установлен и работает?
Чтобы проверить, работает PHP или нет после установки, нужно ввести в консоль команду:

```bash
php -v
```

### 3. Чем отличается оператор `echo` от `print`?
`echo` отличается тем, что может принимать несколько параметров и не возвращает значение. В то время как `print` может принимать только один параметр и всегда возвращает `1`.
