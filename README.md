# BookHub

## Индивидуальная работа по PHP

**Тема проекта:** разработка традиционного веб-приложения средней сложности с функционалом на стороне сервера.

**Название проекта:** `BookHub`

**Описание:**  
`BookHub` — это веб-приложение для просмотра и управления каталогом книг.  
В проекте реализованы регистрация пользователей, вход в систему, роли пользователей, публичный каталог книг, поиск, добавление книг и административная панель.
