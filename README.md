## Цель работы

## Условие

### Условные конструкции
Используя функцию `date()`, создать таблицу с расписанием, формируемым на основе текущего дня недели.

| № | Фамилия Имя | График работы |
|---|---|---|
| 1 | John Styles | xx - xx |
| 2 | Jane Doe | yy - yy |

Для **John Styles**:
- если текущий день недели — **понедельник, среда или пятница**, вывести график работы **8:00-12:00**;
- в остальные дни вывести текст: **Нерабочий день**.

Для **Jane Doe**:
- если текущий день недели — **вторник, четверг или суббота**, вывести график работы **12:00-16:00**;
- в остальные дни вывести текст: **Нерабочий день**.

### Циклы
Создать файл `index.php` со следующим кодом:

```php
<?php

$a = 0;
$b = 0;

for ($i = 0; $i <= 5; $i++) {
    $a += 10;
    $b += 5;
}

echo "End of the loop: a = $a, b = $b";
```

Добавить вывод промежуточных значений `$a` и `$b` на каждом шаге цикла.

Переписать этот цикл, используя операторы `while` и `do-while`.

### 2. Реализация цикла `for`

```php
<?php
$a = 0;
$b = 0;

for ($i = 0; $i <= 5; $i++) {
    $a += 10;
    $b += 5;
    echo "Шаг $i: a = $a, b = $b<br>";
}

echo "<br>Конец цикла for: a = $a, b = $b";
```

### 3. Реализация цикла `while`

```php
<?php
$a = 0;
$b = 0;
$i = 0;

while ($i <= 5) {
    $a += 10;
    $b += 5;
    echo "Шаг $i: a = $a, b = $b<br>";
    $i++;
}

echo "<br>Конец цикла while: a = $a, b = $b";
```

### 4. Реализация цикла `do-while`

```php
<?php
$a = 0;
$b = 0;
$i = 0;

do {
    $a += 10;
    $b += 5;
    echo "Шаг $i: a = $a, b = $b<br>";
    $i++;
} while ($i <= 5);

echo "<br>Конец цикла do-while: a = $a, b = $b";
```

## Контрольные вопросы

### 1. В чем разница между циклами `for`, `while` и `do-while`? В каких случаях лучше использовать каждый из них?

- **for** — используется, когда заранее известно количество повторений.
- **while** — используется, когда количество повторений заранее неизвестно, и цикл должен выполняться, пока условие истинно.
- **do-while** — отличается тем, что тело цикла выполняется минимум один раз, так как проверка условия происходит после выполнения тела.

### 2. Как работает тернарный оператор `? :` в PHP?

Тернарный оператор — это сокращённая форма условного оператора `if...else`.

Общий вид:

```php
условие ? значение_если_истина : значение_если_ложь;
```

Пример:

```php
$age = 20;
echo ($age >= 18) ? 'Совершеннолетний' : 'Несовершеннолетний';
```

Если условие истинно, возвращается первое значение, иначе — второе.

### 3. Что произойдет, если в `do-while` поставить условие, которое изначально ложно?

Тело цикла всё равно выполнится **один раз**, потому что в `do-while` условие проверяется после выполнения тела цикла.
